DeepSeek Harness 桌面版（便携版）使用说明
==========================================

一、怎么用
1. 把整个文件夹（含 runtime 子文件夹）解压到任意目录，注意：Dsh桌面版.exe 必须和 runtime 文件夹、config.json 放在同一目录，不要单独把 exe 拷走。
2. 双击 Dsh桌面版.exe。
3. 程序会自动在后台启动服务，稍等几秒后自动用 Edge 打开 http://127.0.0.1:3080 。
4. 如果 3080 端口已经有服务在运行，会直接打开、不会重复启动。

二、第一次使用：填入你自己的 DeepSeek API Key
- 打开网页后，进入「设置 → 模型」，填入你自己的 DeepSeek API Key 并保存。
- API Key 是个人密钥，每人用自己的，不要共享。
- 所有会话、设置都会保存在你自己电脑的用户目录下（~/.dsh），关掉程序再开也不会丢。

三、配置（可选）
编辑同目录的 config.json：
  port              端口（默认 3080）
  workspace         新会话默认工作目录，留空 "" 表示用你的用户主目录
  browser           "edge" 用 Edge 打开；"default" 用系统默认浏览器
  startupTimeoutSec 等待服务就绪的秒数（默认 60）

四、停止服务
- 双击 停止服务器.bat 即可停掉后台服务。

五、常见问题
- 打不开页面？看 runtime\dsh-server.log 里的报错。
- 提示找不到运行时？说明你把 exe 单独拷走了，请连同 runtime 文件夹一起放。
